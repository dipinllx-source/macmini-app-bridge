# Proposal

## Why

macmini App 引桥的定位已确定为**个人长期使用的远程入口**：千问与 Codex 的原版界面已能经平台访问（M3），但目前一切都依赖手动——页面会断开（实测 codex-01 约每 5 分钟断开并立即重连一次）、会话 30 分钟闲置即过期且 8 小时硬上限、平台重启后会话全部丢失、电脑重启后平台 / Codex 专用实例 / 千问注入都要人工恢复，本地应用升级后也只能翻日志才知道哪里不可用。旧原型桥已于 2026-11-09 停用，平台成为唯一入口，因此现在必须把“能长期稳定用”补齐。

## What Changes

- **连接连续性**：查明并消除浏览器页面周期性断开；网络瞬断后浏览器自动重连同一会话，已发出但未确认的操作不重放（显示“执行状态未知”）；只有不可恢复时才提示，并给出原因。
- **长期免登录会话**：控制台会话改为“活跃即续期”，默认最长 7 天（`mmab.timeouts.session-max-age` 可配置），会话 Cookie 改为持久 Cookie；实例页面的活动会为其父控制台会话续期。**BREAKING**：默认 `session-max-age` 由 8h 改为 7d，`session-idle` 语义改为可配置（默认与最长期限一致，即只要 7 天内有使用就不过期）。
- **会话与审计持久化**：会话（仅存 token hash）与审计记录写入本机 SQLite，平台重启后会话仍有效、无需重新登录；租约与票据仍在重启时作废（防止旧控制权复活），浏览器自动重新获取租约。
- **开机恢复**：平台以用户级 LaunchAgent 开机自启；平台按实例的期望状态负责拉起 Codex 专用实例、以 `--inspect=127.0.0.1:9229` 启动千问并完成注入（注入后立即关闭调试端口）。千问已被普通方式启动时不擅自重启，只在控制台显示“需确认”，提供一键“重启并接入”。
- **异常展示**：控制台改为真实数据——每个实例显示期望 / 实际状态、L0–L4 分层健康、最近证据、异常原因（版本不符 / 升级受阻、端口归属异常、需确认、适配器不可用等）与最近审计；应用升级只做检测与展示，不做自动适配。
- **不在范围内**：应用升级后的自动适配、多操作者 / 多账号、发消息等业务能力的验收、iframe 嵌入。

## Capabilities

### New Capabilities
- `transport/connection-continuity`: 浏览器与实例之间数据面的保活、自动重连、不重放语义与断开原因告知。
- `identity/operator-session`: 操作者会话的期限（可配置，默认 7 天）、续期规则、持久化与撤销；实例会话与控制台会话的关系。
- `lifecycle/boot-recovery`: 平台开机自启，以及按期望状态拉起 / 接入各应用实例（Codex 专用实例、千问带调试参数启动与注入），无法安全接入时的“需确认”流程。
- `console/instance-health`: 控制台对实例状态、分层健康、版本兼容异常与审计的真实展示。
- `audit/audit-log`: 审计记录的持久化、保留期与“只记元数据”约束。

### Modified Capabilities
（仓库此前未建立 OpenSpec 规格，无既有能力需要修改。）

## Impact

- **mmab-server**：`identity`（SessionService、Cookie）、`proxy`（BridgeConnection 保活 / 关闭码）、`lifecycle` 与 `persistence`（目前为占位，需实现）、`audit`、新增控制台查询 API；`MmabProperties.Timeouts` 语义变更；新增 SQLite JDBC 依赖与迁移脚本。
- **sdk/web**：`transport.js` 增加自动重连、请求状态未知语义、断开原因上报。
- **adapters**：千问需要由平台调用的注入流程（复用 `tools/inject.mjs` 逻辑）；Codex 专用实例启动复用 `tools/launch.mjs` 逻辑；两者向平台报告实例状态与版本兼容结果。
- **console**：5 个 mock 页面改为真实数据（总览、实例详情、生命周期、版本兼容、安全与审计）。
- **本机运维**：新增平台 LaunchAgent（取代手工 `~/.mmab/start.sh`）；千问改由平台启动（操作者已同意），不再从程序坞手动打开；已停用的旧 `com.qwenwork.native-web` 不再使用。
- **风险**：Codex 调试端口常开、平台以操作者账号权限操作两个应用（与现状相同，不新增）；持久会话意味着 7 天内未注销的浏览器保有访问能力——需在控制台提供“注销所有会话”。

# ADR-0006：长期会话、会话持久化与租约重新绑定

- 状态：已接受（2026-11-09，OpenSpec 变更 `reliable-personal-entry` 任务组 2）

## 背景

定位为个人长期使用的远程入口：要求 7 天内免重复登录、平台 / 浏览器重启后不必重新登录、页面长期不断线。
M1 的会话全在内存、最长 8 小时、闲置 30 分钟；实例页面的心跳只续租约、不续父控制台会话；租约一旦到期，绑定它的
实例会话随之撤销，用户只能回到控制台重新开窗。

## 决定

1. **期限**：`mmab.timeouts.session-max-age` 默认 `7d`；`session-idle` 留空时等于最长期限（期限内用过就不过期），
   可配置得更短，且不超过最长期限。
2. **持久 Cookie**：会话 Cookie 带 `Max-Age = 会话剩余期限`，其余属性不变（`__Host-`、Secure、HttpOnly、
   SameSite=Strict、Path=/、无 Domain）。实例 Cookie 的期限取父控制台会话的剩余期限。
3. **持久化**：`<mmab.data-dir>/mmab.db`（SQLite，WAL，目录 0700、文件 0600），版本化迁移。只存会话 ID、令牌
   **散列**、来源、创建 / 最近使用时间、撤销标记；**不存**明文令牌、CSRF token（重启后重新生成，控制台加载时经
   `/auth/session` 获取）、租约、票据、口令。续期写库节流为每会话 5 分钟一次。
4. **父会话联动**：实例会话的任何活动（资源请求、同步调用、数据连接心跳）同时续期父控制台会话；父会话失效时
   实例会话随之失效。
5. **租约重新绑定**：租约到期、平台重启、generation 变化后，实例会话不再被撤销，而是解除绑定；下一次访问时以
   父控制台会话的身份重新获取租约（新的 fencing token）。已建立的数据连接固定在建立时的租约上，不迁移——旧连接
   与旧帧仍被 fence 拒绝。租约被其他控制台会话持有时不重新绑定（401；页面提示由连续性任务组处理）。
6. **全部撤销**：`POST /__mmab/api/v1/auth/revoke-all`（CSRF + 口令复核）撤销所有控制台 / 实例会话并关闭数据连接，
   撤销状态持久化。
7. **测试隔离**：测试经 surefire 系统属性与每个端到端上下文的临时 `mmab.data-dir` 运行，绝不写操作者真实数据目录。

## 后果

- 持久会话在 7 天内对拿到 Cookie 的浏览器有效：依赖 HttpOnly / `__Host-` / 精确 Origin 限制窃取面，并提供“注销所有
  会话”。
- **BREAKING**：默认会话期限从 8h / 30m 改为 7d / 7d；M1 测试中“租约到期 / generation 变化即撤销会话”的断言改为
  “关闭旧连接、会话重新绑定新租约”。
- 依赖：`spring-jdbc` 与 `sqlite-jdbc`（版本由 Spring Boot BOM 管理），不引入 DataSource 自动配置与连接池。
